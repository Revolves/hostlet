# 托管页面的平台标识

平台在通过访问授权后的 HTML 响应末尾注入可折叠的右下角浮动标识，显示 Hostlet 名称、实例官网入口和 GitHub 仓库链接。覆盖应用子域、单 IP 路径托管，以及旧版单管理员公开、私有和预览页面。官网和管理工作台不注入。

官网链接使用实例配置的管理 origin，GitHub 指向 https://github.com/Revolves/hostlet。链接在新标签打开，设置 noopener 与 noreferrer。组件使用 Shadow DOM 隔离普通应用样式。

默认仅显示右下角 32px 的 H 图标，鼠标悬停或键盘聚焦后展开 Hostlet 与 GitHub 链接；桌面点击 H 可直接跳转官网。触屏设备点击 H 展开或收起，展开后选择链接跳转，点击外部收起。Escape 可收起键盘或触屏展开状态。

注入不修改已保存的文件、版本和配额，不改变授权、CSP 或访问统计规则。JS、CSS、图片和其他资源保持原样；流式 HTML 响应的 Content-Length 包括标识字节，HEAD 返回相同长度且无正文。

该功能依赖 JavaScript。应用自己的严格 CSP、未闭合的脚本或文本标签、主动删除元素等情况可能阻止显示，它不作为安全或不可移除的水印。平台不会为了显示标识放宽应用 CSP。

部署新版服务后，已有应用下次加载即可出现标识，无需重新上传。仅修改本地源码不会改变线上服务。
