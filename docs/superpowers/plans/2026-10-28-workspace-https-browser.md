# 工作空间本机 HTTPS 浏览器验证

2026-10-28 使用实际工作空间服务、合成账号和独立 Chrome 无头实例验证托管流程。实验在本机使用临时 SQLite 数据库、临时文件和一次性自签名证书；浏览器测试上下文明确忽略证书验证。管理域为 `admin.hostlet.localhost`，应用使用 `*.apps.localhost`，测试 API 也位于本机。邮件由测试发送器模拟，未连接真实 SMTP。结束时关闭浏览器和服务并移除临时数据。

构建后，可在具备 Playwright、Chrome 和 OpenSSL 的环境设置三个绝对路径并执行 `node --no-warnings=ExperimentalWarning test/isolation-lab/workspace-https-browser.mjs`：

- `HOSTLET_PLAYWRIGHT_MODULE`：Playwright 的 `index.mjs`。
- `HOSTLET_CHROME`：Chrome 可执行文件。
- `HOSTLET_OPENSSL`：OpenSSL 可执行文件。

本次会话未提供 Browser 技能，使用独立 Playwright 浏览器；测试不读取用户浏览器配置或已有 Cookie。它不属于默认 `npm test`，需单独运行。脚本不打印票据、分享令牌或 Cookie 值。

本机 HTTPS 浏览器测试了私有 ZIP 的子目录入口：无斜杠地址跳转到带斜杠地址并保留查询参数，目录页面的相对脚本正常加载；密码分享访问同一目录也可加载。服务端测试另行检查未授权请求和缺失入口的处理。

当所选 ZIP 入口本身位于子目录时，根地址经授权后跳转到入口文件，确保相对资源按入口所在目录解析；本机浏览器通过团队成员访问和版本回滚验证脚本加载。服务端测试覆盖查询参数、未授权访问和文件名中的百分号。

托管文件按块传输，服务端测试使用 24 MiB 临时文件和暂停的本机连接验证维护操作等待文件流关闭；客户端断开或测试用短传输期限到期后可继续维护。生产默认单次后端响应期限为 5 分钟。此测试不是并发容量或真实网络性能压测。

验证通过的范围：注册、邮箱验证、登录、上传两个私有 ZIP，打开私有 HTML 和嵌套 CSS/JS；应用专属 Cookie 的 Secure、HttpOnly、SameSite、路径和 host-only 属性；两个应用各自的本地存储、未授权跨应用资源的服务端拒绝、跨应用读取及跨域管理写入的阻止；本机模拟外部 API 请求；服务工作线程注册被 CSP 拒绝；密码分享、撤销后的资源拒绝；公开和私有切换；管理端撤销应用授权后资源拒绝。票据交换请求使用可信管理 origin，Referer 最多包含 origin，测试检查票据和令牌未出现在请求查询参数中。

后续扩展使用第二个独立账号和 390×844 的成员端视口：创建团队和私有应用，选择多入口 ZIP，替换版本并回滚；成员提交申请前和待审批期间无法访问，批准为查看者后可访问但不能编辑；切换为编辑者后可编辑，改回查看者后再次被拒绝；移除成员后，其已有的私有资源访问立即失效。

成员主动退出后，已有私有应用访问立即失效，可以再次申请并经所有者批准加入；最后一位所有者尝试退出时被拒绝。此流程在隔离浏览器及临时数据库中验证。

团队操作记录验证覆盖所有者查看拒绝、批准和移除事件，以及查看者的记录接口被拒绝。记录从数据库版本 21 升级后开始生成，不追溯已有操作；版本 22 开始记录应用上传、版本、访问设置和分享管理等操作。

本机浏览器还验证了个人空间应用创建记录，以及团队应用上传新版本和回滚记录；接口集成测试覆盖分享创建、撤销、应用删除与可见性变更，并通过注入失败验证分享创建和可见性变更的事务回滚。

团队应用版本回滚后，在浏览器中删除历史版本并继续使用当前版本。另在临时服务中保持一个受保护操作未结束，验证历史版本删除等待维护排空；无权删除的成员在维护开始前被拒绝。

新增验证覆盖移动视口下的注册、登录、上传并打开个人应用，检查管理页面没有横向溢出；团队所有者拒绝申请后，申请者仍无法访问，并可重新申请，再经批准加入。还通过界面创建带到期时间的分享，在访客已经打开应用后，将临时测试数据库中该分享的到期时间改为过去，验证已有资源请求被拒绝、再次打开提示过期以及管理列表显示已过期。此处是人为触发到期状态，不是等待真实期限流逝的验证。

进一步在 390×844 视口验证个人应用的密码分享创建、访客打开和撤销后访问失效，检查创建及访客页面没有横向溢出。同一视口也完成管理员注册开关、保留策略、空间配额、举报停用和恢复操作，并检查管理页在加载数据后没有横向溢出。这是 Chrome 模拟视口测试，不代表真实手机或其他浏览器验收。

通过临时数据库设置应用数量和存储配额，验证上传触及两种限制时显示对应处理建议；存储不足时切换中文检查提示，并验证替换已有版本也显示存储不足提示。这些额度只用于测试，不修改实际实例配置。

管理员使用独立浏览器会话登录，验证初始注册开关显示与实例配置一致，关闭注册后实际注册请求被拒绝；通过界面调整个人空间配额，配置并恢复保留策略；访客提交举报后，管理员停用和恢复公开页面并标记举报已解决，内容访问随停用状态变化。保留策略测试的邮件发送器是模拟实现，未实际发送邮件或等待清理周期。

公开应用举报从管理站点首页进入独立表单；测试检查非本平台地址被拒绝、本平台地址可提交，且请求不包含地址中的查询参数和片段。管理员在独立会话中查看并解决该举报。托管应用页面本身不注入举报控件，部署者需公布管理站点举报入口。

举报列表还验证了应用停用与恢复后，同一应用的多条举报同步展示状态；应用已删除的历史举报仍可标记为已解决，且不显示停用或恢复按钮。状态在加载或操作时更新，其他会话的并发操作仍需刷新查看。

举报列表分页测试在临时数据库中添加 55 条历史举报：管理员加载后续记录并处理其中一条；加载期间插入的记录不会造成已有较早记录遗漏。刷新列表可查看最新举报。

2026-10-29 增加密码找回验证：匿名会话申请重置，已登录会话打开模拟邮件链接并设置新密码，链接片段被清除；页面回到登录界面，另一旧会话无法访问工作空间，旧密码无法登录，新密码可以登录。测试发现并修复重置后前端仍显示旧登录状态的问题；邮件仍由模拟发送器提供。

同日模拟找回邮件发送失败：界面给出检查垃圾邮件、重试或联系管理员的指引；恢复模拟发送后可重新申请并完成重置。为保护账号隐私，界面提示不确认邮箱是否存在或邮件是否成功投递；真实邮件服务的故障和投递仍需部署时验证。

管理员使用独立会话查看模拟邮件故障，服务状态显示最近一次账号邮件发送失败。自动化接口测试另行确认匿名访问被拒绝，状态不包含邮箱或错误原文；状态为进程内数据，重启后清零。

使用临时数据模拟所有者邮箱未验证后，管理员在服务状态中查看受影响应用标识、空间及问题类型；接口测试确认匿名请求被拒绝，诊断响应不包含邮箱。

同一标签页再次打开同路径的分享或加入链接时，浏览器可能只更改地址片段。测试发现原页面会继续使用旧状态，且新片段留在地址栏；现通过重新加载目标页面读取新链接，浏览器测试确认新令牌生效、片段被清除，并完成拒绝后的重新申请。

实验发现原管理页面的 `Referrer-Policy: no-referrer` 使 Chrome 对跨域表单 POST 发送 `Origin: null`，导致票据交换返回 403。将管理页面策略改为 `strict-origin` 后，浏览器发送准确的管理 origin，服务端仍严格校验 origin；分享和托管资源的独立安全头仍使用 `no-referrer`。相关响应头有集成测试，修复后上述本机 HTTPS 浏览器流程通过。

2026-10-29 补充自然到期检查：通过管理接口创建短时分享，在浏览器打开私有应用并加载资源，等待真实时间到期后，既有应用会话的资源请求被拒绝，重新打开分享也提示失效。该短时分享通过接口创建；管理界面时间输入仍按分钟设置。实验使用临时数据库、本机自签名 HTTPS 和模拟邮件。

同日在独立浏览器会话验证账号注销：团队唯一所有者的注销按钮被禁用并显示需先转移所有权；另一个只有个人空间的合成账号在再次输入当前密码后成功注销，界面回到登录状态并提示可用同一邮箱重新注册。真实 HTTP 集成测试另行确认个人应用文件、团队成员关系和会话均被清理，匿名化账号记录可重新注册同一邮箱，且安全日志不包含密码、Cookie 或邮箱。

本实验不能证明真实证书信任链、通配 DNS、生产反向代理、多个浏览器或真实外部 API 的表现；尚未完成所有移动端核心流程的浏览器验收。服务工作线程限制和服务器撤销也不能收回访问者已经下载的数据。正式公开服务前仍需在目标部署环境验证这些事项。
