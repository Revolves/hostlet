能力

让作品被看见，
也保留边界。

Hostlet 只托管静态文件，不运行你的服务端代码。简单，反而让发布这件事更清楚。

01

独立地址

每个应用都有自己的稳定入口，更新版本时地址不变。

02

访问统计

只统计真正打开入口文档的访问，静态资源和预览不会混进数字。

03

版本历史

保留最多 20 个版本。一次上传失误，不会让上一版消失。

04

私有分享

默认私有，按需公开。分享链接可以撤销，也可以加密码。

05

团队空间

个人空间之外，也可以建立团队，按所有者、编辑者和查看者分工。

06

开放接口

每个用户都能创建自己的 API Key，用 CLI 或 Skill 发布应用。

发布之前

先把几个问题说清楚。

适合发布什么作品？

个人主页、作品集、可视化报告、静态小工具和 AI 生成的 HTML 页面。支持 HTML、ZIP，CLI 还支持目录发布；需要构建的项目先生成静态产物。

发布后所有人都能看见吗？

新应用默认私有。你可以按需切换公开，或生成带密码、有效期的分享链接。只有公开应用会进入官网公开目录。

必须安装 CLI 才能使用吗？

可以直接在工作台上传。Skill 安装器自动附带独立 CLI，无需再全局安装；支持官方服务和通过 HOSTLET_URL 指定的自建实例。

可以运行后端或数据库吗？

Hostlet 托管静态前端，不执行服务端代码，也不提供数据库或 SPA fallback。外部 API 需要自行部署，并确认跨域和认证配置。

更新作品后，旧链接还能使用吗？

替换同一应用的版本时地址保持不变。可查询保留的历史版本、回滚、修改标题，也可删除历史版本或应用。

可以自己部署吗？

可以，代码使用 MIT 许可证，仓库提供宿主机部署说明。官方实例是开源演示平台，采用单域兼容模式。面向不可信用户的自建服务应按部署文档完成隔离与运维验收。
