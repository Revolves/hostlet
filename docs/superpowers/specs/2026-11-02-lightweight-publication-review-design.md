# 轻量发布审核

个人空间保持直接公开。团队中编辑者可提交当前私有应用的公开申请，由团队所有者批准或驳回；所有者可直接公开。申请仅针对提交时的版本和修订，版本或内容变化后不能批准旧申请。保留一条当前申请及可选审核意见，操作写入团队审计。

公开团队应用的内容更新必须重新审核。为避免未经审核的内容直接公开，上传新版本或回滚前须先转为私有；用户可继续用私有访问或分享预览。现有已公开的团队应用保持公开，后续公开切换和版本更新遵循上述规则。私有分享是独立的授权方式，不经过公开审核。

服务端事务内重新检查角色、空间、应用和修订；查看者不能提交或决定，非所有者不能批准或驳回。撤回公开立即生效。申请、决定与公开状态及审计同事务写入；删除应用或空间时清理申请。界面显示待审核状态、审核结果和意见，并提示公开应用需先转私有才能更换版本。拒绝公开不阻碍私有预览。

验收包括权限绕过、并发操作、过期申请、升级后既有公开应用、更新与回滚、审计失败回滚，以及网页端和接口验证。数据库升级和测试使用临时数据；已有服务器不自动升级。
