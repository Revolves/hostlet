发布流程

三步，作品就有自己的位置。

没有复杂构建，没有服务器配置。你只需要准备好文件。

  1. 01

    选择文件

    上传单个 HTML，或包含 CSS、脚本和图片的 ZIP。入口文件会自动识别。

    HTML / ZIP
  2. 02

    获得地址

    应用会得到稳定地址。后续更新不会改变链接，旧版本也会被保留。

    your-app.apps.hostlet.cn
  3. 03

    决定谁能看见

    默认私有。准备好后再公开，或创建可撤销、可设密码的分享链接。

    private → public

能力

让作品被看见，
也保留边界。

Hostlet 只托管静态文件，不运行你的服务端代码。简单，反而让发布这件事更清楚。

01

独立地址

每个应用都有自己的稳定入口，更新版本时地址不变。

02

访问统计

只统计真正打开入口文档的访问，静态资源和预览不会混进数字。

03

版本历史

保留最多 20 个版本。一次上传失误，不会让上一版消失。

04

私有分享

默认私有，按需公开。分享链接可以撤销，也可以加密码。

05

团队空间

个人空间之外，也可以建立团队，按所有者、编辑者和查看者分工。

06

开放接口

每个用户都能创建自己的 API Key，用 CLI 或 Skill 发布应用。

CLI / SKILL

把发布，
交给一条命令。

在账户设置里创建 API Key，然后让命令行或 Agent 直接完成上传、替换和版本查询。

  • 官方实例默认使用 https://hostlet.cn
  • 自建实例通过 HOSTLET_URL 切换
  • Key 只在创建时显示一次，可随时撤销
创建我的 API Key →
hostlet / publish 
# 设置凭据
export HOSTLET_TOKEN="hlt_..."

# 发布一个目录
hostlet publish ./dist \
  --workspace WORKSPACE_ID \
  --title "My portfolio"
