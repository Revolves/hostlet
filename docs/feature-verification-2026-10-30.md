# 功能核验与待办清单

核验日期：2026-11-05（文件名保留原日期以兼容既有链接）。范围依据多用户托管设计，以及后续讨论的 CLI、Agent 和开源交付方向。状态分为“已实现并有验证”“部分实现”“未实现”和“待环境验收”；不以旧路线图中尚未更新的复选框计算完成率。

## 本次验证

- Windows、Node 22.21.1、npm 10.9.4：`npm test` 共 365 项，363 通过、0 失败、2 跳过，耗时约 115 秒。跳过项为“Windows 无符号链接能力”和“POSIX 文件权限不可用”，本次不将其计为通过。
- `npm run build` 通过，构建 46 个前端模块。
- 全量测试需要访问本机回环端口；在受限沙箱内会以 `EACCES 127.0.0.1` 失败，最终在非沙箱环境完成。该限制不是应用错误。
- 修正了三处测试自身的问题：启动日志断言仍等待旧的 `Hostlet admin:`、迁移测试硬编码旧 schema 版本、实例锁测试缺少启动超时。修正后相关测试和全量套件均通过。
- 新增 CLI 回滚与分享命令测试、Bearer 分享路由测试，以及真实应用中的 `read`/`publish`/`share` 作用域和回滚集成测试。
- 新增 8 项 CLI 帮助、版本、未知命令、凭据脱敏和打包清单测试。`npm pack ./cli` 只包含 `hostlet.js`、`package.json`、`README.md` 和 `LICENSE`；本地 tarball 在 Windows 干净目录安装成功，安装后的 `hostlet --help`、`hostlet --version` 和 `hostlet help share` 均通过。
- 官网目标在真实 Chromium 中完成 1440px 桌面、390px 和 320px 移动视口检查；覆盖分页加载、搜索、空状态、接口失败重试、中英文切换、SEO 元数据和横向溢出。测试使用临时公开应用数据和本机隔离服务，未触碰现有 `data`。
- 本地 `master` 分支尚未推送；本轮 CLI 打包与帮助改动已纳入本地提交。
- 截至 2026-10-30 的独立 Chrome 与本机自签名 HTTPS 实验通过：账号、团队审批和角色变更、私有托管、分享与撤销、配额、账号注销和平台治理等流程。使用临时数据、模拟邮件，不能代替生产域名和真实邮件浏览器验收。
- 此前的独立私有访问实验 1 项测试通过；本机 SMTP 协议实验通过 TLS、STARTTLS、认证、收件人拒绝和证书校验，以及模拟邮件验证与重置。
- 上述测试使用临时数据库、合成账号和测试文件；未触碰现有 `data`。本次未重新部署服务器或重复发送真实邮件。

## 待办：优先完成的功能

- [x] **F1 发布幂等与不确定结果恢复。** CLI/API 创建和替换支持持久幂等键、冲突检测和结果查询，并覆盖断线、并发和进程中断。回执当前不自动过期，长期清理策略仍待处理；现有服务器尚未升级。
- [x] **F2 CLI 补齐版本回滚和分享。** 已支持按当前修订号回滚；列出、创建和撤销私有分享，并处理 `share` 权限、STDIN 密码、ISO-8601 有效期、结构化错误与审计。创建分享不具幂等性，网络中断或 5xx 后必须先查询现有分享；现有发布默认为私有。
- [ ] **F3 CLI 可发现性和交付。** 已补齐 `--help`、`help <command>`、命令级 `--help`、`--version`、独立包清单、包内 README/LICENSE 和本地 tarball 安装说明；JSON 输出已有自动化覆盖，并在 Windows 干净目录验证了安装、帮助和版本输出。剩余：确认 `hostlet-cli` 包名与公共 registry 可用性、实际发布、Linux/macOS 实机验证及发布后安装验证。
- [ ] **F4 Agent MCP 接入。** 基于同一授权和发布能力提供受限工具，覆盖列表、私有发布、版本和分享；验证令牌保护、权限撤销、超时及错误传播。删除和公开发布不应作为默认能力。
- [ ] **F5 Agent Skill。** 编写可安装的使用说明和验证场景，引导确认实例、空间和文件范围，默认私有，避免输出凭据，并对不确定结果先查询再重试。
- [ ] **F6 上传兼容性提示。** 设计可安全完成的静态资源引用检查并报告缺失资源；对动态引用、外部 API、CORS 和运行时行为明确无法完全静态判断，避免把提示误作兼容保证。
- [ ] **F7 管理配置体验。** 明确是否需要在管理界面配置 SMTP 和实例级上传硬上限；如需要，设计凭据保管、测试连接、重启或热更新及权限审计。当前已有环境配置能力，界面未实现。
- [x] **F8 公开官网产品化。** 已增加中英文切换、公开目录服务端分页/加载更多、最近更新/最多访问排序、搜索、SEO 与分享卡片、空状态、错误重试、无障碍和移动端细节；首页导航已精简为品牌、语言和工作台入口。当前没有人工推荐位或运营配置，排序仅由更新时间和访问数驱动。
- [ ] **F9 路由权限端到端验收。** 使用临时数据和本机浏览器覆盖公开首页、账户、工作台、页面管理、平台管理、单管理员模式重定向、401 会话失效和停用应用；该验收不需要正式域名，但需要可访问本机端口的浏览器环境。

## 待办：正式上线及自部署验收

- [ ] **V1 域名和 HTTPS。** 准备两个不同可注册域、应用通配解析和受信任证书，在目标代理上验证未知 Host 拒绝、私有资源及独立 origin。
- [ ] **V2 真实邮件全链路。** 在目标部署环境用实际邮箱通过浏览器打开验证及重置链接；核验邮件送达、重放、过期和旧会话撤销。继续排查 IMAP/POP 客户端未看到网页邮箱中测试邮件的原因；这不影响已确认的 SMTP 投递事实。
- [ ] **V3 标准部署与恢复。** 在干净环境原样运行仓库示例 Compose，验证容器重启、持久数据、升级、当前 schema 版本 27 的迁移及完整备份恢复；若有旧页需迁移，在受授权的备份副本上演练。禁止直接对现有用户数据试错。
- [ ] **V4 安全与容量。** 对真实代理和部署方式验证可信来源、令牌保护、限流及滥用处置，尤其覆盖分享/票据兑换；执行容量与并发测试，接入磁盘、证书、邮件及服务告警和安全日志采集。
- [ ] **V5 运营准备。** 由实际运营者确定主体、隐私与用户协议、个人信息权利请求及投诉渠道，落实内容受理、停用和恢复流程，并向主管部门或接入方确认适用手续。
- [ ] **V6 客户端验收。** 在目标域名上用多浏览器和真实移动设备完成核心流程，核对私有资源、分享、密码重置和撤销行为；本机 Chrome 模拟视口不等同真实设备验收。
