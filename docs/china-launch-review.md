# 中国大陆公开体验上线准备记录

核查日期：2026-10-29。适用于拟面向中国大陆用户开放的官方体验实例；其他自部署实例应按其实际经营主体、部署地点、服务范围和适用法律另行核查。以下是启动准备，不代表已完成备案或合规验收，也不预判主管部门对具体业务的认定。

## 经营主体与接入

- 确定实际运营主体、服务所在地、域名和接入商。用户可自行上传并公开前端页面，业务范围不能仅描述为展示运营者自己的静态网站。
- 《互联网信息服务管理办法》区分经营性许可和非经营性备案；项目是否属于特定业务、免费体验与后续收费的具体分类，应结合实际模式向接入商、所在地通信管理部门及专业顾问确认，不能因为开源或免费就自行认定无需许可。参考 [互联网信息服务管理办法](https://xzfg.moj.gov.cn/front/law/detail?LawID=1756&Query=%E4%BA%92%E8%81%94%E7%BD%91%201%202) 与 [电信业务分类目录](https://qhca.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_0a66ad8c82c94c77bf56d698a1f35d64.html)。
- 根据主管部门及接入商要求，确认管理域、应用域、通配子域及页面应展示的信息，并完成适用手续后再开放。当前尚无正式域名、运营主体信息或备案结果，仓库也未提供真实备案编号。

## 个人信息与账号

- 梳理邮箱、密码摘要、会话、团队成员关系、分享、举报和审计等实际处理的数据，明确处理者、目的、保存期限或确定方式、第三方邮件服务及用户权利渠道。正式隐私规则须由实际运营者提供并核实，不能使用占位主体信息上线。[个人信息保护法](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm) 对告知和保存期限有规定；[网络数据安全管理条例](https://www.cac.gov.cn/2024-09/30/c_1729384452307680.htm) 对个人权利请求及注销后处理等有规定。
- 当前提供注册、验证、找回密码和密码确认注销。注销会删除个人应用及文件、移除团队关系、撤销会话，并拒绝团队最后所有者；内部保留匿名化账号 ID 作为团队内容和外键锚点。本机隔离浏览器已验证成功注销及最后所有者阻止，临时 HTTP 集成测试验证了文件、关系和会话清理；真实 SMTP、生产数据恢复及正式通知流程仍未验收。仍缺少面向用户的隐私规则、个人信息权利请求渠道、运营主体联系方式、备份及依法需保留记录的处置说明；这些必须由实际运营者补齐并完成流程演练后再开放注册。

## 内容治理与网络日志

- 当前已有公开举报入口、管理员审核和应用停用；仍须确定运营负责人、公开管理规则、投诉举报受理及反馈流程、处置和报告机制，并验证实际运行。适用范围及具体义务应结合服务形态确认；参考 [网络信息内容生态治理规定](https://www.cac.gov.cn/2019-12/20/c_1578375159509309.htm)。
- [网络安全法](https://www.cac.gov.cn/2025-12/29/c_1768735112911946.htm) 对网络运营者监测、记录网络运行状态和安全事件，以及按规定留存相关网络日志不少于六个月作出规定。应用现已提供按 UTC 日期轮转、默认保留 180 天的脱敏接口日志，记录粗粒度路由、状态、耗时和服务端来源地址，不记录请求体、Cookie、查询参数、密码或令牌；仍须把日志纳入独立监控、告警、访问控制、备份恢复和生产查询演练。Compose 示例仍关闭容器日志，不能单凭本机文件日志证明满足适用要求。
- 日志内容、权限、轮转、清理和运维限制见[安全日志说明](security-logging.md)。需要哪些事件、如何脱敏及保存多久，应由运营者依据适用要求确定；不能简单开启全部访问日志代替安全设计。

## 待完成的环境验收

真实域名和通配解析、受信任 HTTPS、SMTP 投递、实际代理和镜像、外部安全监控、生产备份恢复、内容治理人员及流程均未验收。仅在上述事项和适用手续完成后，才能对公开运营作出判断。
