# 发布幂等与结果查询设计

状态：已按本设计实现，尚未部署到现有服务器。范围为现有 CLI/API 的新建应用和替换版本；保留现有网页上传行为及现有版本回滚机制。

当前回执不自动过期，账号注销或工作空间删除时会清除对应回执；长期运行可能产生存储增长，清理策略仍待设计。Node 22.13–22.15 的事务兼容路径已通过模拟测试，尚未在这些版本实机验证。

## 用户体验

CLI 每次发起新的逻辑发布生成一个随机请求 ID，发送前显示该 ID，并允许用户通过 `--request-id` 在重试时复用。CLI 提供 `publish-status --workspace <id> --request-id <id> --json` 查询；如果结果不确定，先查询，同一逻辑发布只能使用原 ID 重试。查询无需再次上传文件。请求 ID 不是凭据，仍需要有效的 API 令牌及当前工作空间权限。

服务端返回 `in_progress`、`succeeded`、`interrupted` 或 `not_found`：`succeeded` 返回当次提交的应用 ID、版本 ID、修订号和提交时的响应快照；`interrupted` 表示已确认该次尝试没有提交且可用相同内容重试；`in_progress` 应稍后查询；`not_found` 不能证明请求永远不会到达，应使用相同 ID 重试而非生成新 ID。页面后来被修改、删除或权限被撤销时，查询遵从当前访问权限，并将历史发布结果与页面当前状态区分。

## 请求与冲突

每个请求 ID 是高熵、受长度限制的随机值，按账号、工作空间与 ID 唯一；创建和替换共享这一命名空间，其他用户或空间不能读取其结果。CLI 上传前计算实际上传文件的 SHA-256 与字节数，通过请求头随请求 ID 一起发送；服务端读取实际文件后重新计算并校验，不能信任客户端声明的摘要。请求指纹覆盖操作类型、工作空间、目标页面、预期修订、标题、入口、源文件名、文件长度和内容摘要；规范化规则须和服务端实际解析一致。

同 ID 同指纹在已有成功结果时返回原结果，不产生新应用、版本、配额消耗或重复发布审计。同 ID 不同指纹返回明确的 409 冲突，不覆盖原记录。并发重试最多允许一个写入者，其他请求返回进行中或已完成；不能依靠进程内锁实现持久性。完成结果保留至少 30 天；超过保留期后的行为需要明确提示，不能承诺无限期去重。旧 CLI 未提供请求 ID 时继续按既有语义处理，文档明确其不具备自动重试安全性。

目录发布必须确保相同文件树生成可复现的归档字节（固定排序、时间和 ZIP 元数据）；如果无法保证，CLI 应保存本次实际待上传归档供重试，不能仅对不同字节的 ZIP 假定内容相同。对复用请求 ID 但本地文件已改变的情况，拒绝重试并提示用户新建发布。

## 持久化与恢复

新增版本化 SQLite 迁移和发布请求表；记录包含请求 ID 的安全摘要、身份与空间、请求指纹、状态、提交结果及时间，不保存令牌、文件内容或原始秘密。首次接收时以事务原子占用请求 ID；提交应用/版本、配额和审计时，在已有 `quotas.commit` 的同一数据库事务中把请求改为成功并记录响应。数据库事务失败时绝不返回成功。

发布文件继续使用现有暂存与 `workspace_publication_journal`。启动时在监听前先执行现有发布日志恢复，再将没有成功结果且不再有活动写入者的进行中请求安全标为中断。数据库已提交但响应丢失时，成功记录必须仍可查询；文件移动后数据库未提交时，按现有日志回收，并保留可重试状态。活动请求不能被后台过期清理或其他进程误判为中断；当前仅支持已有单实例锁模型。

接收前验证鉴权和请求头，持续计算请求体文件摘要并遵循现有上传大小、配额、临时文件日志和维护租约。上传中断、摘要不匹配、授权撤销、文件系统或数据库失败要释放预留资源，不能留下虚假成功；如资源回收失败，沿用现有失败关闭与启动恢复机制。查询和重放都重新检查账号、令牌作用域与当前工作空间权限。

## 接口与兼容

- 创建和替换 CLI 发布接口新增请求 ID、内容摘要及长度头；服务器必须验证头唯一、语法和上限，并对声明与实际内容不一致返回 400。
- 新增只接受 Bearer 凭据的结果查询接口，避免通过 URL 传递认证令牌；同步调整单 IP 管理端防护的严格路由匹配和限流。
- CLI 令牌继续通过环境变量提供，不在命令输出、日志或文件中写入令牌。请求 ID 可用于恢复但不作为授权凭据。
- 现有独立域名和单 IP 模式均覆盖；生产部署必须先备份并演练迁移，不能直接操作现有服务器数据。

## 验收

1. 相同请求连续及并发重试只创建一个应用或一个新版本；返回的 ID、版本和修订一致，配额与审计只计算一次。
2. 同 ID 文件、元数据、目标页面或预期修订不同均返回冲突；摘要伪造、重复请求头及越权查询被拒绝。
3. 模拟中断：未提交、文件移动前后、数据库提交后响应丢失，以及进程重启；恢复后状态正确、现有版本与文件不丢失。
4. 覆盖令牌撤销、成员移除、页面删除、超期记录、上传断开、配额与清理失败，以及目录归档可复现性。
5. 使用临时库运行单元/API 与实际 HTTP 集成测试，验证单 IP 防护与 CLI；运行完整测试及构建。生产服务器及真实数据不在本次测试范围内。
